# Fidelity to the paper's runs

Legend.

- **Identical**: byte-identical to the paper's runs; **verified** means checked against the as-run requests (the
  request hashes or prompt files the paper's pipeline recorded) on SWE-Gym tasks: pydantic__pydantic-8650 and
  facebookresearch__hydra-2062 (screens, FN rating, environment, FP replay), facebookresearch__hydra-1006 (witness,
  review and debate of both families, from the as-run execution records), facebookresearch__hydra-1725 (repair writer,
  the checks G2 and G3 and the specification block, from the as-run defect record and triage plan).
- **Ported**: the as-run code, carried over with module plumbing changed (paths, model calls, record I/O, the names of
  flags, reason codes and record fields) and comments edited; the logic is unchanged.
- **Re-implemented**: written from the paper and the released rules, not from the as-run code.

Where fidelity and generality conflicted, the as-run behaviour is the default and the dataset-specific part is a
setting.

Names. The step ids (1a ... 7a), the repair checks G1-G5 and the escalation letters are explained in the workflow
guide ([`WORKFLOW.md`](WORKFLOW.md#names), "Names"). Flags, reason codes and output fields carry the names of this
release, which follow the dataset's data card; naming them changed no prompt, user message, request tag or decision
rule. File paths that do not start with `taskaudit/` are relative to that package directory.
